# Lucien Verhoeven — situs karakter (GitHub Pages)

Situs statis satu berkas (`index.html`), tanpa build tool. Tokoh orisinal untuk roleplay gelap (dead dove).

## Pasang di GitHub Pages
1. Buat repositori publik baru, mis. `lucien-verhoeven`.
2. Unggah `index.html` (dan README ini) ke cabang `main`.
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
4. Tunggu 1–2 menit. Alamat: `https://USERNAME.github.io/lucien-verhoeven/`

Tautan langsung ke tab: `#cover`, `#letter`, `#backstory`, `#ledger`, `#voice`.
Gambar tinta sudah tertanam di dalam `index.html`, tak perlu berkas lain.
